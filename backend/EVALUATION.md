# Проверка реального Mistral API — 18 октября 2026

Модель: `ministral-8b-2512`, официальный Mistral API. Промпт финального прогона: `world-lens-extraction/1.1.0`. Ключ использовался только локально, не включён в отчёт или Git. Это ограниченный smoke/evaluation прогон, а не оценка качества на репрезентативном корпусе.

## Автоматические проверки

58 backend тестов проходят с injected provider и временной SQLite: 22 авторских сценария, ISO/цитаты/направления/модальность, API, авторизация, повторная и конкурентная обработка, явный retry, отдельный учёт попыток, бюджет, неподтверждённый тариф, 429/backoff, 401, 5xx, timeout/потеря соединения, неполный JSON, отсутствие usage, предупреждение на 80% и месяцы UTC. Ещё 33 существующих frontend/globe теста проходят. TypeScript backend и production frontend собираются. Эти тесты не обращаются к реальному API и не доказывают качество самой модели.

## Реальный прогон 22 публикаций

Финальный промпт исправил наблюдавшуюся в первом прогоне генерацию полного многостороннего графа. Ошибка сквозной нумерации evidence refs в некоторых multi-event ответах всё ещё встречается и блокируется, а не незаметно исправляется или отправляется на повторный платный repair. Для комментаторского и неоднозначного текста пустой результат безопаснее искусственной связи. Из этих 22 коротких примеров нельзя делать вывод об отсутствии ложных связей в произвольных новостях.

## Реальная публикация и браузер

Через форму AI Lab вручную передан короткий фрагмент [публикации GOV.UK о вступлении UK–India FTA в силу](https://www.gov.uk/government/news/historic-uk-india-free-trade-agreement-is-now-in-effect), опубликованной 17 июля 2026. Модель извлекла GB ↔ IN, trade, completed; evidence сохранена с исходными offsets; итог Unverified/NeedsReview. Финальный запрос: 1 263 input / 422 output tokens, оценка $0.00025275. Повторное нажатие Analyze показало cached и не увеличило число AI-запросов. Проверен просмотр raw JSON.

Ранее отдельный реальный smoke test успешно разделил одну фразу о санкциях Германии против России и помощи Украине на два announced события с корректными directed связями. Объявление не стало фактом доставки.

Суммарно за два fixture прогона, smoke test и две версии анализа реальной статьи: 47 запросов, 52 154 input / 12 582 output tokens, локальная оценка $0.0097104. Это оценка приложения, не подтверждение фактического списания у провайдера. Исходные local runs и machine-readable отчёт сохранены локально и исключены из Git.
